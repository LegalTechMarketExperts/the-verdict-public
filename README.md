# The Verdict by The LegalTech Market Experts: public data

Published automatically from LTME's private register. Read by ltme.news.

- `register/`: every public story (headline, link, dates, outlet, provenance, LTME's own summary), one
  file per day and per month, the last 90 days in `register.json`, a search index in `search.json`.
- `editions/daily/`: each daily edition once Jeremy Hill has approved it, with `editions/index.json`.

Publisher text, private excerpts and review notes are never published here. Corrections and removal
requests: jeremy.hill@ltme.news.
